# Requirements
## Functional requirements
- FR1 Allow the user to perform CRUD operations on tasks
- FR2 Allow tasks to be sorted into categories
- FR3 Store tasks to and retrieve tasks from a local file between program executions 
- FR4 Allow users to output tasks sorted into categories

## Non-functional requirements
- NFR1 IO should be understandable and actionable for a technical audience
- NFR2 Must handle unexpected errors gracefully without crashing
- NFR3 Reading tasks by category or id, and adding tasks, must not take longer than 0.5s
